# Novel Craft rebirth

Approved scope: rebuild the existing public repository, preserve history, support both generation from scratch and deliberate revision, merge verified changes, and publish an installable update where the existing publishing authorisation permits.

## Architecture
A dependency-free Node 22.14+ runtime replaces npm's platform-specific binary dependency. The Rust implementation remains a legacy source path with its existing real tests; it is not the new runtime. Modules separate the filesystem transaction engine, context selection, category catalogue, model runner, generation workflow, exports, and CLI contract.

The writer owns taste. The existing host agent owns model access. Novel Craft owns persistent state, traceable proposals and bounded execution. The default model adapter invokes an already authenticated Codex CLI in read-only mode; a shell-free JSON stdin/stdout adapter supports other agents. No model credential is collected or stored.

## Canon and manuscript contract
Markdown chapters remain directly inspectable. Immutable content objects and revision manifests back them up. HEAD is advanced only after a write-ahead journal has materialised all changed manuscripts. A pending transaction blocks normal operation until explicit recovery. Changes require a proposal, an expected revision and source hashes. Manual edits are detected and can be explicitly adopted; they are never silently overwritten. Canon facts cite exact supporting excerpts and distinguish world facts, beliefs, reader knowledge and plans. Inferred facts are candidates until explicitly accepted.

## Generation and craft
An actual bounded plan -> draft -> evidence-backed review -> optional revision workflow produces prose, not merely instructions. Every stage is checkpointed; resuming verifies the base revision and source hashes. A failed provider call preserves prior outputs. A full run is one reviewable proposal. Acceptance is opt-in, including separate approval of extracted facts. Models are not treated as objective judges; no keyword-based literary score is shipped.

Category coverage is an explicitly dated snapshot of the accessible NovelFull catalogue, not falsely attributed to unavailable NovelFullbook. Aliases distinguish genres, demographics, formats and content labels. Each supported craft profile has original examples, nonbinding review questions and attributable reading references. Explicit-sex catalogue labels are recognised as metadata with non-graphic adult relationship guidance only. Sexual-minor categories are unsupported. No hosted novel is scraped or bundled.

## Required proof
Local Node tests exercise transactions, conflict prevention, recovery, accepted memory in subsequent context, source excerpts, category coverage, provider failures, bounded/resumed generation, exports and strict CLI JSON. Cross-platform CI executes the same runtime tests and the preserved Rust tests. Package proof requires packing, installation into a clean prefix and invoking the installed binary. Real-model prose quality and an external npm publish are separate proof levels, reported honestly.
